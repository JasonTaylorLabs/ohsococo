Changed `.jscpd.json` to use `"format": ["typescript"]` with `"formatsExts": { "typescript": ["ts", "tsx"] }`. jscpd 4.x tokenises JSX attribute expressions (`={...}`) as separate `javascript` segments, causing every `.tsx` file with such attributes to be counted twice (as `tsx` and `javascript`). This one-file config fix tells jscpd to use the typescript grammar for both extensions so files appear under a single format. Result: `npm run quality:dup` reports 14 files / 1034 lines (was 21/1375), exits 0, and finds 0 clones.

Added a module-level `SITE_URL` constant in `src/lib/paths.ts` that strips all trailing slashes from `site.url`, preventing double-slash URLs (`/ohsococo//`) in sitemap, robots, and JSON-LD when the owner hand-edits `site.url` with a trailing slash. Added three unit tests: trailing slash tolerance, multiple trailing slashes, bare domain (no slash). All 28 unit tests pass; `typecheck`, `lint`, build output verified. E2e failures are pre-existing CSS/font/fixture issues unrelated to this change.

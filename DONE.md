Fixed the Notify me button's focus indicator in Windows contrast themes by adding `forced-colors:focus-visible:outline-offset-2` to the submit button's className. A 2px gap ensures the ring renders on white Canvas pixels at rest, giving a well-over 3:1 change-of-state ratio against hover/rest (WCAG 2.4.13 AAA). The class compiles only under `@media (forced-colors: active)` so normal-colour rendering is unchanged. Added one unit test and two e2e tests (forced colours and normal colours, both desktop and phone) to guard the behavior.
